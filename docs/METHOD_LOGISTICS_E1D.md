# E1d：因果时序累积单模块消融

## 问题和方法来源

E1c显示0.5–1倍工况内尺度偏置难以由逐点q99检测。E1d检验持续同方向的偏离能否通过历史累积检出。EWMA是经典统计方法；其递推和alpha=1退化为逐点统计的性质见[NIST EWMA说明](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc324.htm)。此模块不能单独作为算法首创声明。

## 定义

输入为观测x、当前可用工况记录r和按train_fit拟合的E1c参考。令z为既有训练标准化后的观测、delta=z-mu_r、P_r为精度矩阵。

- 边际有符号残差：u_j=delta_j/sqrt(Sigma_r,jj)。
- 条件有符号残差：u_j=(delta P_r)_j/sqrt(P_r,jj)。
- 累积统计：h_(t,j)=alpha*u_(t,j)+(1-alpha)*h_(t-1,j)。
- 告警统计：d_(t,j)=abs(h_(t,j))/q_(r,j)；alarm为d>1；一致性分数w=exp(-d²/2)。

绝对值在时间累积之后计算，使相反方向偏离可以抵消。它不是污染概率或产品质量分数。alpha预先固定为0.2；alpha=1为无累积对照，不在本轮验证集上选参数。

每条新序列从h=0初始化；可见工况记录改变时清空该序列全部通道状态。不可用残差保持NaN并清空其通道状态，下一次可用时重新从0更新。条件残差需完整同刻观测，因此一通道缺失会令该行所有通道不可评分；未知记录同样不可评分。没有从隐藏真实工况重置，也不在事件开始/结束时重置。

重置规则是方法的一部分；当前未单独验证不重置消融、长运行热启动或断续采样效果。初始值和静态经验阈值会让启动早期较保守，不抹除这些时间步。

## 校准和公平比较

复用E1c train_fit参考。对原train_cal完整序列计算每种残差和alpha的h，再逐工况逐通道取abs(h)的经验q99。保留时间相关结构，不套用独立正态稳态控制限。所有方法的名义分位数预算相同，但验证集实际误报率未必相同；不得写成已严格匹配部署FPR。

720个校准点的分位数存在1/720的计数分辨率，q99实际校准告警可为8/720≈1.11%；这不是部署保证。calibration_audit.csv记录每通道阈值、支持数和实际告警率。alpha=1还必须逐场景、逐view与E1c保存的分数和告警复现一致。

## 输入与评价

配置`configs/logistics_e1d.yaml`指定E1c源运行。读取前校验其177个产物哈希，输入manifest记录源元数据hash。仅对已有val运行；test没有新评分。保持5种子42–46、10场景及事件位置完全不变，比较2种残差×2个alpha。

逐点报告E1c相同指标和all/stable/transition、真实状态分层。另报告false_onsets_per_1000_clean_cells：每1000个干净可评分单元上的假告警启动次数，启动按全序列false→true计算后再分层。它与告警占用率FPR不同。

事件统计以每个注入块的每个污染通道为一条事件记录，包含：

| 指标 | 定义 |
| --- | --- |
| any_active_hit | 事件期间该通道任一告警为真，包括开始前已活跃的告警 |
| fresh_onset_hit | 事件期间出现false→true的新告警，开始前已活跃不自动视为新检出 |
| pre_active | 事件开始前一步告警是否已为真；序列起点记false |
| fresh_delay_detected | 成功新检出事件中，首次新告警距事件开始的步数；失败为NaN |
| fresh_delay_capped | 成功时使用实际延迟，漏检记事件持续时长；不是实际检测时间或生存估计 |
| post_event_fpr | 污染结束后12步内原受影响通道的干净单元告警率；重叠窗口去重，排除再次污染单元 |

结束之后才出现的告警不算事件检出。事件时长4/6/12步等不统一，截断延迟须结合时长；仅成功事件的平均延迟存在选择偏差。clean副本在相同事件时间窗也计算事件指标和拖尾支持率，可检查随机告警巧合；observed拖尾还可能受其他通道污染影响，不全部归因于本通道记忆。

先逐seed汇总事件，再计算5个种子的均值和样本标准差。时间点或多个事件不视为独立实验。EWMA减逐点的配对差保存到表中，实际FPR/拖尾增加时不能只报告Recall收益。
