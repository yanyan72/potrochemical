# E1f：受控事件与经典CUSUM对照

## 研究问题与冻结协议

E1c的污染比例预算同时改变事件长度，起点局限于12步网格。E1f用新的同分布模拟开发验证序列，分别改变事件时长、每序列数量、幅度和相对工况切换的起点。配置见`configs/logistics_e1f.yaml`，正式评价前冻结，不从结果选择k或alpha。

种子42–46，每种子12条180步序列，三个初始工况各4条。新随机命名空间20260921；只生成新validation，不生成或评价test。沿用E1c train_fit参考及尺度、E1d已经校准的逐点和alpha=.2 EWMA；新CUSUM仅用同一train_cal完整序列校准。新验证集仍属于开发数据，同分布并不证明外部泛化，不能跨E1c/E1f数值直接归因。

## CUSUM与评分

对标准化有符号边际或条件残差u，双侧递推为：

`Cplus[t]=max(0,Cplus[t-1]+u[t]-k)`，
`Cminus[t]=max(0,Cminus[t-1]-u[t]-k)`，`s[t]=max(Cplus[t],Cminus[t])`。

预设k=.5，对应经典1标准差目标偏移的参考值；公式依据[NIST/SEMATECH CUSUM Control Charts](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc323.htm)。CUSUM是经典基线，不是本项目首创。序列起点、可见工况记录变化和缺失后重置；未知工况不可评分。不得依据隐藏真工况或污染标签重置。

每工况每通道train_cal统计量q99为h，告警为s>h，连续分数为`exp(-.5*(s/h)^2)`，表示一致性而非正确概率。本版本不在告警时重置，以评价连续评分和恢复；与经典停机/报警后重启策略不同，不具有基于独立输入的ARL保证。相同名义q99不保证相同实际误报，必须报告clean FPR及拖尾。

## 单因素对照

基准为固定状态、每序列2个12步事件、1倍train_fit工况内尺度偏置。另设时长4/24、数量1/3、幅度2/4；所有事件一次只污染一个通道。污染行比例为count×duration/180，不能在改变前两者之一时同时保持比例。

随机起点先生成3个候选，按最大24步事件、至少12步间隔、末尾12步恢复窗约束，再随机排列。数量对照取嵌套子集；时长/幅度对照固定起点、通道和符号。整数起点脱离12步网格，但并非全时刻独立均匀采样；约束使边缘时刻和密集事件未覆盖。

切换每60步发生，随机事件组与固定状态组共享标准化创新及事件安排；另设可见记录延迟12步，观测与真值完全不变。定点起点为60/120边界的-6、0、+6步，符号和通道配对。起点改变会改变跨工况暴露和累积状态，不能归因为纯粹的单一物理机制。每个场景与其compare_to仅有一个配置因素变化。

## 指标与证据链

6种组合在相同序列上计算：2残差×逐点/EWMA/CUSUM。保存clean/observed两视图、全部时刻/稳定/切换窗口、逐工况指标，以及共同支持与全时间轴Recall/F1、可评分覆盖、clean/bystander/post-event FPR。

事件指标沿用E1d/E1e：事件前已经告警不能自动计新检出；同时保存任意命中、新告警命中、已检出延迟、漏检按事件时长截断的延迟、截断延迟/时长、可评分比例。跨时长比较优先同时看归一化延迟和原始步数。按种子先聚合，再报告5种子均值和样本标准差；相位分层同时保存各种子样本量，不把稀少分层等同于全体。

所有数据、模型、原始分数、事件设计、配对差、图和哈希落盘；代码提交早于正式实验。评分入口只有观测与可见工况，标签仅用于评价。clean oracle训练、瞬时理想转场、单通道段偏置、抽象时间步仍是局限。
