## Purpose
交付已冻结算法在弱污染、污染比例、多通道偏置及状态记录延迟下的成对模拟证据、五种子表图、论文主张边界，并上传GitHub。用户2026-09-19授权继续开发与上传。

## Current state
基准41f4834。E1b五种子固定状态实验已完成；分状态边际为当前主基线，条件残差有牵连。32测试通过。当前没有真实质量标签；旧结果保留。

## Scientific assumptions
全部synthetic，抽象采样步。训练仍为理想可靠固定状态片段。验证转场采用已知均值/尺度瞬时切换且保留标准化扰动连续性，不代表真实运输转场动力学。观测与真实状态分开；算法只接收可用状态记录。延迟d步仅使用t-d的状态，序列开头沿用首状态。单一分段偏置，幅度以对应工况train_fit样本标准差计量；多通道时各通道独立随机正负号，不声称覆盖所有协同故障。

## Scope
保持五种评分算法、训练拟合和独立校准不变。对照baseline为固定状态、2倍工况内尺度、10%污染行、1通道；分别变化强度0.5/1/4、比例2%/20%、通道数2，及即时切换与延迟4/12步。切换即时相对固定baseline仅改变过程状态；延迟相对即时切换仅改变提供给算法的状态。不训练新预测器，不查看test。

## Data leakage controls
只用train_fit拟合参考与工况内污染尺度，train_cal校准。评分只接收observed与recorded_regimes；true_regimes与mask只用于生成/分层评价。验证与test完整序列隔离；新压力场景仅生成val，test保留E1b生成数据且不评分。方法和阈值不在validation重新拟合。

## Reproducibility
种子42–46；场景共享clean标准化扰动、污染随机流、训练参考。强度场景共享mask和方向，延迟场景共享clean/observed/mask。按seed计算均值/样本标准差及配对差，时间点不视为独立重复。配置、参考、事件、每场景数据与得分、逐种子分状态/转场指标、图、元数据落盘。目录拒绝覆盖。

## Validation
