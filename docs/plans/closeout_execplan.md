# 评分组件 v0.1 收尾执行计划

## Purpose
按2026-09-27用户要求完成当前储运传感器评分原型、上传GitHub并交付整个项目报告。论文、质量预测与真实数据部署分别列出状态。停止探索性算法扩展。

## Current state

## Scientific assumptions
模拟、抽象等间隔时间步、理想可靠训练、已知/延迟记录。分数不是正确概率或产品质量。真实数据不可用，不声称工业验收。

## Scope
冻结边际EWMA alpha=.2、q99、记录改变/缺失/序列边界重置为工程默认；点评分及条件EWMA作为固定对照。默认选择依据可解释性和较少通道牵连，并非所有场景最优。演示模型预选seed42，禁止按test选种子。统一JSON模型、CSV批量评分、严格字段/单位/顺序验证、示例；保留集收尾验收不命名E1h。

## Milestones
1. 冻结FINAL_EVALUATION_PROTOCOL及配置；仅检查源代码和开发/训练材料。
2. scoring_component.py + score_batch.py；校验模型/数据、缺失/未知状态、因果性、序列隔离与直接API一致；测试只用人工夹具/开发数据。

4. 更新状态/验收/任务/证据/总报告，回归和文档命令验收，提交上传，核对远端。

## Data leakage controls
参考与阈值只从已审计E1f模型加载；不训练/调参。测试噪声来自E1c原保留序列，独立事件随机空间20260927。隐藏真状态只用于生成/评价，评分仅观测与可见记录。检查train_fit/train_cal/val/test身份互斥；原test曾存于公开仓库，因此是流程保留集，不声称外部保密盲测。完成后该test视为已用，未来开发不能称它为未见测试。

## Reproducibility
5种子42–46，每种子12序列×180步；12成对场景复用同一测试序列，不能视为144条独立序列。4固定方法；每seed计算后mean/sampleSD。保存配置、输入manifest、模型、场景数据、评分、环境、源码/产物hash。无阈值收益门槛；功能验收和科学性能分别报告。

## Validation
