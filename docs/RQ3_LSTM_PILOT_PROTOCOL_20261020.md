# RQ3 普通 LSTM 开发验证协议（运行前冻结）

日期：2026-10-20。主仓库 yanyan72/potrochemical。用户已明确本轮研究按无法取得真实数据的条件推进；证据范围限于合成机制，真实数据不再是当前执行前提。

## 研究问题和不变条件

复用已发布重建版 rq3_paired_20261019_rebuild_v1 的10,000个基础批次，不生成、覆盖或重新挑选基础数据。已有岭回归开发结果显示连续评分尚无稳定增益。本次只更换预测器为普通单层LSTM，检验分数增量是否随预测器改变。标签仍为未物理标定的180步累计温度暴露代理与独立null代理，不代表产品实测质量。输入为预测时已可见的118步；全部截止点仍在运输阶段。

五个数据种子42–46，每种子train1000、val250；reference_fit150和reference_cal100独立拟合/校准评分。test500/seed保持未作预测评价。审计可能读取test检查结构与标签随机流，区别于模型评价。

## 输入、对照和训练

复用上一阶段输入构造及分工况边际EWMA .2/q99/reset。直接载入并核验上轮存档的评分/填补参数，重新计算的训练分数作为随机对照库。

- mean：train标签均值。
- B0：观测和缺失标识。
- B2：B0加工况one-hot及评分可用性；当前定义下可用性与非缺失冗余，不再重复拟合B1。
- B3：B2加连续分数。
- B2Q/B3Q：分别再加按train统计标准化后的观测平方项。
- B2R：B2加由既有固定规则抽取的随机训练分数轨迹，检验附加特征与容量的替代解释。

把原展开特征还原为[批次,118,通道]，每个通道的中心和尺度只从所有train批次/步计算，区别于岭回归的逐时间位置标准化。训练期恒定特征在所有划分置零，避免从未训练的缺失/可用性输入权重在验证时产生任意响应；意味着本协议不学习缺失机制。保存恒定列掩码并明确此限制。

普通单向LSTM、1层、32隐单元，全部可见隐状态做时间均值后接线性标量输出，无注意力、修复、物理约束或分数加权。每个目标单独训练；标签只用train均值/标准差标准化。使用均值汇聚是累计暴露任务的预设读出方式，不从结果挑选。该模型不是所有LSTM结构的代表。

AdamW lr=.003、weight_decay=.0001、batch128、40epochs、梯度裁剪1，标准化目标MSE损失；每轮记录原始val MAE，选择最小MAE轮次（精确相等取最早）。各组预算一致，没有学习率/隐宽搜索。每组/目标/数据种子1个优化随机种子2000+10*data_seed+target_index；打乱种子9000+10*data_seed+target_index，各组共享打乱顺序。不同输入维度导致参数数目不同，同seed不保证相同初始化张量；B2R提供容量对照。五个重复含数据与优化随机性，不能分别估计优化方差。CPU float32、单线程、确定性算法；记录实际环境。

## 评价与可解释性边界

锁定所选checkpoint后评价同批次10个val视图：原始、偏置1/2/4、漂移1/2/4、缺失、记录延迟6/12。幅度是配对条件，不是批次抽样类别。原始train不注入故障，不从压力视图调参。

主配对B3−B2；次比较B3Q−B2Q、B2R−B2，报告MAE差及相对原始视图的退化差。报告五种子均值、样本SD、MAE/RMSE、截止工况、故障通道/时长分层和null。逐批预测和每轮训练/验证曲线全部保存。与已发布岭回归并列展示，但不同模型的优化/预处理预算不同，不把跨架构差异全归于网络结构。

val已被上一轮研究查看且本轮用于checkpoint选择，全部结论是开发验证；不作显著性或真实工业有效性声明。负面结果保留，不以结果为依据重新模拟数据。新模拟机制、故障增强和最终test另立协议。当前代理/过程尚未按具体产品机理标定，需要导师审查模拟合理性。
