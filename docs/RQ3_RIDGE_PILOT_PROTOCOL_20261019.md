# RQ3 岭回归开发验证协议（2026-10-19）

本协议先于本轮正式拟合结果提交。复用 `rq3_paired_20261019_rebuild_v1`，不重新生成基础批次。本轮为导师审核准备第一阶段的可复现拟合与开发验证结果，不是完整预测研究的最终验收；普通 LSTM 和新 test 的最终评价保留为后续阶段。

## 数据、目标与范围

每数据种子 reference_fit=150、reference_cal=100、train=1000、val=250；五种子42–46分别拟合和报告。test不用于拟合、选择或预测评价。先执行来源及标签语义审计；该结构审计可核验test文件和负对照公式，但不计算预测指标。目标 arrival_proxy 和 null_proxy 都是合成代理；只读过去118步输入，目标为180步固定终点，单位任意。

基础目录manifest SHA-256固定为 `a2224ee148d8b5d61a5cb24fd225d5d56817fc17ebd37753545c8494d7ca47ed`；原生成器SHA-256固定为 `c63312c1236bb703c841203bd5300a8c4712f38231ef21741b10b94ede76571b`。新增审计代码不修改原发生器和旧metadata。

## 评分与输入

复用现有 `fit_sensor_reference`、`calibrate_temporal`、`score_temporal`：reference_fit观测拟合标准化及分工况LedoitWolf参考，reference_cal的118步序列独立校准q99；边际有符号残差EWMA alpha=.2，序列起点、缺失和记录变化重置。整数工况先映射为配置定义的字符串；无未来值、隐藏真值或事件标签作为预测特征。

训练组逐通道中位数填补缺失。每组将全部118步特征展开成一条批次特征向量，再仅用train拟合逐列均值和标准差；恒定列尺度设1。二元缺失、one-hot工况和评分可用性均明确保留。无注入训练中某些特征恒定，线性系数将为零，不能声称模型学会了缺失应对。

|组别|特征|
|---|---|
|mean|每目标的训练均值|
|B0|观测+逐通道缺失标识|
|B1|B0+逐时刻三类工况one-hot|
|B2|B1+逐通道评分可用性|
|B3|B2+连续分数，不可评分处填0|
|B2Q|B2+按训练通道均值/尺度标准化后的观测平方，维数与分数块相同|
|B3Q|B2Q+连续分数|
|B2R|B2+与目标独立的随机分数块|

B2Q/B3Q用于检验加入简单非线性项后分数的增量；不能穷尽所有非线性解释。B2R按固定种子及批次ID的SHA-256，抽取一条train原始分数轨迹，保留时间/通道相关性；相同批次所有视图使用同一随机轨迹，不可评分处同样填0。ID仅用于可重现随机对照，不进入预测特征。抽样不读取目标，有限样本下不保证零相关。

在已知工况、边际评分、当前重置方式下，可用性恰等于观测非缺失，B2与B1信息重复；应数值核验其预测等价。本轮B3–B2不能独立证明“可用性”的额外作用。

## 拟合与选择

各组、各数据种子分别拟合岭回归；每目标只在相同三个alpha候选 `[1,100,10000]` 中按原始val MAE选择，平局选列表中靠前值。目标截距不惩罚，不标准化目标；所有组均使用训练组无人工故障的观测。随后锁定所选模型，评价全部val视图，不再按故障条件重新选择参数。保存每个候选的原始val误差。

模型组采用相同alpha搜索预算，但特征维数不同，不能声称完全相同模型容量。岭回归无随机初始化；随机对照种子单独记录。原始val参与选择，故包括压力视图在内的结果都仅作为开发验证证据，不当作独立最终测试。

## 配对评价与汇总

共10个val视图：原始、偏置1/2/4倍、漂移1/2/4倍、缺失、原始观测下记录延迟6/12步。同批次事件时长、位置、通道、符号固定，幅度是逐一施加的配对条件；时长从4/12/24步预先抽样。延迟与注入故障不混合。

保存逐批次预测、MAE/RMSE、逐种子差值、相对原始观测的误差增量，以及差值的差值。按基础原始观测在截止时点的工况分层；故障视图另按事件通道和时长分层（分层信息不作为输入）。每种子先算指标，再报告五个独立数据重复的均值和样本标准差；副本和时间点不扩充独立样本数，不宣称统计显著性。

主对比B3–B2，负数表示MAE降低；次对比B3Q–B2Q、B2R–B2。两个目标全部报告，不能删除负对照的偶然收益或失败结果。记录train与各val视图的评分分位数、可用率、恒定特征数，用于解释正常训练到故障评价的分布变化。
