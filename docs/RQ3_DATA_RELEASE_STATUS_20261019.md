## 恢复原产物后的只读验收

1. 找到原始 `rq3_paired_20261019_v1` 目录或其无损压缩包，先备份并记录压缩包与目录总大小，不覆盖、不重新生成。
2. 核对 `metadata.json`、`config.yaml`、`manifest.json`、`audit.json`，确认生成源码身份、依赖、五个种子、各 split 数量和 `data_source: synthetic`。
3. 从该目录执行 `python -m src.rq3_paired_data --audit <原目录>`，重新比对 manifest 中每个 SHA-256、输入/真值分离、ID 与标签、可见时间、污染副本及记录延迟；只读审计不得训练预测器或计算测试集预测指标。
4. 复核通过后以原字节上传整个目录，远端逐路径比对 SHA-256 和文件数；上传后在此记录远端提交及验收结果。若源文件缺失或哈希不符，保留异常并停止把该批数据称为已发布数据。

本阶段不含真实储运数据，也没有 RQ3 质量预测实验结果。文件哈希只能证明完整性，不能证明测量真实性或预测效果。
