# 多工况 Trust Score 主线与 SBS 并行探索：研究判断及最小实验方案

日期：2026-10-28｜状态：完成现有证据核查和方案设计，尚未执行本文件提出的新实验。

## 1. 研究方向纠正与本轮判断

**路线 A 是论文主线：原有多工况研究 → 工况不确定性及传感器异常的相互作用 → 评分机制与预测融合 → RQ3 验证。路线 B 是并行探索：SBS 科学可行性 → 最小实验 → 判断能否形成应用证据。** 企业数据不足不阻塞 A；也不因企业提供 SBS 数据而替换原研究对象、标签机制或核心主张。

此前“保留负结果、收窄论文论断”是阶段验收时的选项。导师现在明确要求继续探索多工况不确定性，不能再把收尾负结果作为唯一推进方向。此前讨论稿若给人“转向 SBS 即可解决 RQ3”的印象，本文件予以纠正。

| 来源 | 明确内容 | 当前地位 |
|---|---|---|
| 导师要求 | 原思路下不同工况及其不确定性继续论证；企业方案另行试验、检验可行性 | 必须落实的双线研究方向 |
| 先前讨论 | 工况不确定性感知、参考可靠性判断、选择性融合 | 候选工具，不是导师指定算法，也不是已成立创新 |
| 本轮建议 | 先查“记录错误与传感器故障共存”的可辨识性，再验证评分能否指导有益的预测修正；参考可靠性作为条件触发的备选 | 尚待实验检验 |

**当前 RQ3 仍未获得稳定预测增益支持；但是现有实验没有排除新的机制改进。优先级是提出并证伪明确机制，不是继续增加同分布数据。**

### 本轮代码核查发现的明确空白

1. `src/rq3_paired_data.py::apply_view` **主动拒绝同时施加工况记录延迟与传感器故障**。旧 RQ3 十视图主要分别改变这些因素，不能推断二者共存的交互作用。
2. 重建配置为三种工况、三通道，预测时点 119、可见观测 0—117、完整过程 180 步。真实过程采用工况均值/尺度切换，而不是经现场标定的连续热动力学。
3. `arrival_proxy` 是完整过程温度超阈值累计暴露加噪声；湿度、振动仅有间接信息。**本轮不改标签、不增强湿度或振动系数来制造收益。**
4. 旧门控按可见工况记录选参考中心。即使理想故障指示知道记录错位，仍可能把观测拉向错误中心。因此旧 oracle 不能当成所有修正方法的性能上界。
5. 未充分解决：记录不可靠时如何区分真实切换与故障、参考覆盖外如何避免过度确信，以及评分的检测价值何时能转化为预测价值。

评分由可见数据和训练得到的固定参考计算。“独立增益”应指相同信息、模型容量和预算下的经验增量，不能理解为评分创造了新的物理测量信息。对于固定参考和全部原始输入，确定性评分不会增加条件互信息；它可能通过表示、先验和有限样本效率带来收益。

## 3. 三个可证伪的候选方向

下面的数学关系说明研究依据，不代表已证明新算法有效。建议先推进候选一与候选三，候选二保留为有证据时才启动的分支。

### 候选一：区分“工况证据不确定”与“传感器不可信”

**科学问题：** 同一个低分，究竟来自传感器异常，还是记录滞后、真实工况切换？只凭当前可见历史，哪些情况下能区分，哪些情况下根本不可区分？

设真实工况为 Z，可见记录为 R，观测为 X=X*+B+ε，B 为传感器故障。现有按记录选参考的残差可写为：

`X_j − μ_j(R) = [X*_j − μ_j(Z)] + B_j + ε_j + [μ_j(Z) − μ_j(R)]`。

最后一项不是传感器故障，却进入同一个残差。拟检验：由截至当前的历史、记录及其他通道得到 `q⁽⁻ʲ⁾_t(z)`，对待评价通道 j 使用留通道的工况推断，再计算混合参考预测密度：

`p₀(x_j | 可见历史) = Σ_z q⁽⁻ʲ⁾_t(z) p₀(x_j | z, 可见上下文)`。

根据独立校准数据，把密度偏离转换为可比较的分数；同时保留工况不确定性，不能把混合密度或熵直接叫作“故障概率”。留出通道 j 是为了减少“故障自己解释成新工况”的循环，其他通道同时异常时仍可能失效。

**可辨识边界：** 对等先验的两种原因，若可见历史分布分别为 P、Q，最优二分类错误率为 `(1−TV(P,Q))/2`。P=Q 时任何方法都不能可靠辨别原因，应承认不确定。先做一个分布完全相同的数学单元例证，防止通过隐藏变量或事件编号获得虚假高准确率。

**区别与创新门槛：** 多模型状态/模式估计、HMM/HSMM 早已用于故障诊断和阶段变化，不能把“加入概率工况”当作首创。[L1][L2] 可能的贡献是：建立评分错误来源的可辨识边界，并证明在记录与故障共存时，留通道推断相对普通软工况基线减少错误归因，且确实改善下游预测。必须同时与硬工况、普通软工况混合比较。

**否证条件：** 只能在真工况 oracle 下改善；留通道版本没有超过普通软混合；或检测改善但预测不改善。出现这些结果时分别收窄为信息不足、无额外机制优势或仅检测收益，不称 RQ3 成功。

### 候选二：评分是否知道“自己的参考不够可靠”

**科学问题：** 工况看似确定时，参考样本少、覆盖不足或参考受污染，能否使评分过度确信？工况熵较低不意味着参考可信。

对工况 z 的参考参数 θ，预测不确定性满足全方差分解：

`Var(X | D,z) = E_θ[Var(X | θ,z)] + Var_θ[E(X | θ,z)]`。

前项是工况内随机性，后项是参考估计不确定性；两者不应一概归为故障。可先按独立参考批次重采样，估计评分波动与参考支持程度；不能按相关时间点重采样制造大量独立信息，也不能把 bootstrap 波动当成参考偏差已被消除。

**最小验证：** 仅当候选一发现剩余错误随参考支持明显变化，再在同一开发过程上比较完整参考和预先固定的减半参考；其他数据、标签及故障不变。污染参考和未知工况留作后续单独压力条件，不同时展开全因子搜索。

**区别与创新门槛：** 概率软测量、参考不确定性和适用域判断已有研究。[L3] 这里需要证明的是“参考可靠性”能预测错误修正风险，并且比单纯增大残差阈值、加入工况熵更有用。不能把经典方差分解或重采样当作创新。

**否证条件：** 可靠性指标仅降低所有样本权重，无法识别高风险修正；或性能与不使用 Trust Score 的通用不确定性模型相当。此时不能归功于 Trust Score。

### 候选三：从“异常程度”转向“是否值得修正预测”

**科学问题：** 相同的低分，什么时候应保留原观测，什么时候可以修正？温度、湿度、振动对当前目标的重要性不同，是否能解释“评分更准确但预测未改善”？

保留原始预测 f₀，另有修正预测 f₁，输出 `f_g=f₀+g(f₁−f₀)`，其中 0≤g≤1。令 e₀=f₀−Y，d=f₁−f₀，在可见门控信息 U 下，平方风险变化为：

`ΔR(U)=2g E[e₀d | U]+g²E[d² | U]`。

当分母非零，条件最优权重为 `clip(−E[e₀d|U]/E[d²|U],0,1)`。这只是平方损失下的关系；正式 MAE 仍需直接配对检验。**低 Trust Score 并不保证修正方向 d 与原误差 e₀ 反向，因此不保证收益。**

拟用训练集的按批次分组折外预测估计修正是否有益；验证集只按冻结规则选模型。测试标签、未来过程、真工况和故障 mask 不进入可部署门控。参考不可靠时可退回 f₀，但 f₀ 也可能错误，不承诺逐样本安全。

**区别与创新门槛：** 专家混合和选择性预测已有成熟研究。[L3][L4] 本候选要保留全部样本输出，不能只拒绝困难样本后汇报低误差。需要超过相同预算的无评分门控、随机评分门控与普通软工况基线，才可能支持评分有额外价值。

**否证条件：** 只比直接拼接好，但未优于无评分门控；只在强温度故障好而正常/记录错误明显退步；或者收益仅来自增加参数。均不满足当前 RQ3 目标。

## 4. 路线 A 的最小实验与停止规则

### A0：先验证评分归因机制，不训练新的大型预测器

- **数据：** 复用旧重建版种子 42、43、44，各取固定编号的前 60 个 train 批次和前 60 个 val 批次，共 360 个已有基础批次。旧 val 已被研究使用，明确作为开发集，不称新盲测。参考继续使用对应 reference_fit/reference_cal。
- **六个配对视图：** 记录正确/延迟 12 步 × 无故障/1 倍弱漂移/4 倍偏置。每基础批次保留同一潜在过程和标签；形成 2160 个视图，不是 2160 个独立批次。
- **故障安排：** 持续 12 步；三通道、正负符号、切换前 6 步起始/切换后 18 步起始，按固定表平衡。相同故障在正确记录与延迟记录下幅度完全相同，先按原参考尺度确定故障，再改记录。不得因记录变化而重新计算注入幅度。
- **边界：** 真实切换时刻只用于模拟干预安排和评估分层，不能输入评分器；可部署的时序推断仅用当时已经可见的历史。首次实验仍沿用旧过程，不新增连续转场、未知工况、污染参考或新质量公式。
- **比较：** 原硬记录评分、普通软工况混合、留通道软工况混合；真工况版本只作单列诊断，不作为理论上界或可部署模型。
- **冻结前提：** 实现前保存软工况似然、转移/记录模型、校准方式、输入白名单及固定参数；只从参考/开发训练数据估计，不直接把注入事件的真延迟告诉评分器。参数选择预算同等公开。
- **输出：** 干净误报、事件召回及延迟、干净通道牵连、模式识别混淆、记录错误与故障并存时的表现。以相同开发校准误报预算比较，完整报告召回代价；不只优化一个 F1。

增设无泄漏、相同标签、观测配对、输入可用时间、原数据哈希未变的检查。新联合扰动在独立模块中实现，不修改旧冻结协议，也不覆盖旧结果。

**A0 决策：** 三个种子均列出结果。只有误报改善没有以明显丢失故障检出换取，且普通可见信息能区分部分原因时，才值得进入 A1；具体校准目标及可接受代价在运行前写入执行协议。小样本用于筛查机制，不以“显著”或一次最佳结果宣称发现创新。若普通软混合已解释全部改善，保留这个结论，不强行包装留通道机制。

### A1：有机制依据后，再做有上限的预测验证

不扩建 10,000 批数据。复用三个开发种子的原 1000 批 train，采用独立开发验证分组和上述六视图；联合故障训练日程对所有组一致。主目标继续使用原 arrival_proxy。

**最多六组、每数据种子两个独立优化种子，共 36 个完整训练流水线；不进行超参数网格搜索：**

1. 原始无评分预测基线；
2. 原评分直接拼接，作为旧方法连接组；
3. 不含评分的通用融合门控，使用相同原观测、工况后验及公共输入；
4. 同一融合结构＋原评分；
5. 同一融合结构＋候选一评分；
6. 同一融合结构＋随机训练评分轨迹。

组 3—6 是归因比较，统一网络结构、公共特征、参数预算、训练日程、预处理和优化种子。零评分、真实评分、随机评分使用相同预留输入槽。若包含两个预测分支或折外训练，**全部拟合和门控训练计入总预算**，不能把额外拟合藏在“36 个模型”之外。单分支组 1—2 只是连接基线，不以其较小容量证明评分创新；执行前另存准确拟合数和更新数上限。

主比较为候选评分组相对无评分门控和随机评分门控的六视图等权 MAE 差；并完整给出正常、延迟、联合故障及三通道结果。对比组 5−4 判断收益是否来自新评分，而非仅改融合。若第 3 组已取得同等收益，贡献只能归于通用融合或工况表示。

**统计单位：** 先在同批配对视图内比较，再汇总到各数据种子；两个优化种子用于观察训练波动，不把 3×2 当成六个独立数据重复。分别列出数据种子与优化种子的结果；仅三个外层种子的开发试验不承担确认性显著性结论。时间点、故障视图和同一基础批次不能充当独立样本。

**确认与停止：** 本轮先不安排新大样本确认。仅在 A1 有一致机制和有实际意义的收益线索后，冻结唯一候选、实际意义门槛、正常场景容许损失、主比较、独立数据种子/优化种子设计及一次新测试。未来样本量根据开发方差与预先确定的最小效应估算，不反复追加直到显著。候选只在预选子组有效时，结论限制在该条件；整体无收益必须原样保留。

## 5. 路线 B：SBS 方案的独立可行性判断

### 5.1 有科学动机，但尚未形成企业预测验证条件

原始实验文献说明热储存会涉及基质老化、聚合物变化与相分离。一项研究在特定材料和条件下发现软化点上升；另一项长时储存研究发现先升后降，且上下部软化点差减小不必然代表性能恢复。[L5][L6] **这支持研究储存影响，但不支持给所有 SBS 统一指定单调规律。** 材料配方、初始状态、热历史和取样位置都可能影响观测。

绝对软化点、上下部软化点差、实验室老化后软化点是不同目标，不能混为一列标签。文献条件不能直接当作企业实际工况或参数标定依据。

现有企业材料以质检结果为主，尚未形成可确认的过程历史—样品—工况—质量配对链；部分记录关系与预测时点仍待确认。它们可以帮助确定现场任务和指标，不能用来反向编写过程，再称真实 RQ3 验证。企业原始表、具体检验数值和现场标识仅在本地保存，本计划不公开这些内容。

### 5.2 最小实验分三种条件开展

| 条件 | 最小工作 | 能回答什么、不能回答什么 |
|---|---|---|
| 当前仅有检验材料 | 核对样品/复检关系、检测方法、普通与老化后指标及预测时间边界；形成可用性清单，不训练复杂模型 | 能判断任务是否可定义；不能估计储温效应或评分增益 |
| 可开展少量受控实测 | 建议由现场/实验室确认一种配方、两个实际可行的储存条件、两个时长，每格三个独立处理容器，共 12 个处理单位，另留初始基线；固定采样位置并记录实际温度历史 | 先检验变化能否区别于检测/取样重复误差。技术复测不算独立处理；小样本不能完成工业外部验证。具体条件由现场确定，未安排企业执行 |
| 无过程实测但需开展模拟 | 单独建立“老化主导、聚合物变化主导、两者竞争”的明确假设模型；固定参数来源和不确定区间，做全情景敏感性对比 | 能发现结论依赖哪些假设；不能识别企业真实参数或证明真实预测增益。没有依据的参数只能标为假设，不用企业末端标签反推过程 |

受控实测首先检验同一材料的变化量 `ΔSP=SP_终点−SP_初始`。跨条件与容器比较，区分处理重复和技术复测；若变化淹没于测量波动，先报告该条件下不足以辨识，不立即扩张复杂预测网络。若条件可行，再讨论前瞻预测：固定预测时点、提前量和当时可用输入，用“初始软化点保持不变”等简单基线评价。

即使储存影响能够重复观察，也只完成 B 的机制可行性。要验证 RQ3，还需要观测可靠性差异以及无评分/真实评分/随机评分的公平对照。真实过程上人工注入故障应标为“真实过程＋人工观测扰动”，与实际故障现场验证分开。

**本轮判断：** 文献论证可以现在完成；当前材料不足以启动真实储存预测模型。SBS 模拟不是默认下一步，优先明确可辨识目标与可行的最小实测。如果这些条件不具备，B 停留在可行性和参数敏感性层面，A 照常推进。

## 6. 双线价值、成本及相互关系

| 比较 | 路线 A：多工况不确定性 | 路线 B：SBS 可行性 |
|---|---|---|
| 当前实验证据 | 已有完整模拟评分与预测对照；RQ3 未支持；发现联合扰动覆盖空白 | 有检验材料和外部文献，尚无现场配对过程验证 |
| 首要问题 | 错误参考与故障能否区分，评分何时有助于预测修正 | 储存条件对目标的作用能否辨识，预测任务是否可定义 |
| 首个交付 | 360 个旧基础批次的小规模配对机制报告 | 文献与数据可用性判断、可选最小实测方案 |
| 后续工作量 | A0 较低；A1 中等且预算封顶；确认实验另行冻结 | 数据核查较低；现场实测等待和配对成本较高，不能承诺完成日期 |
| 潜在论文价值 | 直接针对主线/RQ3，可能形成可辨识性与决策机制贡献 | 提供应用约束或外部佐证；也可能证明该任务目前不可行 |
| 主要失败风险 | 可见信息不足；经典软工况基线已足够；检测改善不转化为预测 | 配方/取样混杂、变化小、缺少过程记录；无法可靠预测 |

B 可以帮助检查哪些机制更贴近实际，但不能把 A 的温度代理改名为 SBS 软化点。A 的方法若以后迁移到 B，需要独立建立输入、目标和时间对应关系，重新验证；两条路线的样本和证据不能混合计数。

## 7. 阶段交付与进度边界

1. **本阶段已完成：** 核查 GitHub 证据；纠正主次关系；提出三个候选及文献差异；给出 A0/A1 有限实验和 B 最小可行性方案。没有新实验结果，没有修改主算法。
2. **下一阶段优先：** 冻结 A0 执行协议并开展小规模评分机制验证，同时整理 B 的可用性与最小实测设计。两项互不等待。
3. **之后按证据推进：** A0 支持可见信息区分时进入 A1；参考可靠性方向仅在诊断需要时开启。B 具备条件才进入实测或独立假设模拟。
4. **每阶段持久化：** 原数据及旧结果只读；新目录保存配置、来源版本、样本编号、随机种子、日志、逐批结果和哈希。阶段完成上传原始项目，远端回读核验并汇报 Commit ID。企业原始资料继续本地保存。
