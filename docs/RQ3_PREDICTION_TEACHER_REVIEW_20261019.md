# 石化储运观测可靠性与终点代理预测：首轮模拟拟合结果（导师审核稿）

日期：2026-10-19  
审核目的：确认研究问题、模拟假设、首轮结果的解释，以及下一阶段实验安排。  
证据类型：合成数据上的训练与开发验证；尚无本轮最终测试、普通LSTM或真实产品质量验证。

## 一、当前结论与研究问题

本阶段已完成五个独立数据种子上的岭回归拟合、参数选择和配对压力评价。模拟温度暴露代理具有可预测性，但**现有连续评分作为附加特征，尚未显示稳定的预测增量收益**。B3相对B2在十个条件中的9个条件出现更高的平均MAE；四倍偏置条件有小幅平均改善，种子间差异较大。该结果应作为方法边界和后续设计依据，不宜写成“可信度评分提高了质量预测准确率”。

拟研究的问题是：在石化产品运输与仓储的环境监测中，考虑当前工况和观测可用时间后，传感器观测的一致性评分能否帮助终点目标预测，并在偏置、漂移、缺失或工况记录滞后时降低误差？

研究链条为：环境观测与工况记录 → 因果一致性评分 → 固定预测模型 → 同批次原始/故障观测配对比较。评分表示与参考分布的一致程度，不是测量正确概率或产品合格概率。

## 二、数据依据与模拟假设

使用已发布的重建版 `rq3_paired_20261019_rebuild_v1`，未重新生成或覆盖其基础数据。原中断对话的正式原件未找回，本版独立标识为重建版本。完整目录有10,000个基础批次、84个文件；82个清单哈希条目和100个配对视图检查条件通过。100指种子、划分、视图条件的组合，不是100次独立重复实验。

| 划分 | 每个数据种子 | 五种子合计 | 本轮用途 |
| --- | ---: | ---: | --- |
| reference_fit | 150 | 750 | 拟合正常参考分布 |
| reference_cal | 100 | 500 | 独立校准评分阈值 |
| train | 1,000 | 5,000 | 拟合预测参数与预处理 |
| val | 250 | 1,250 | 选择岭回归参数及开发验证 |
| test | 500 | 2,500 | 保留，未作预测评价 |

每批模拟仓储→平稳或颠簸运输→仓储，通道为温度、相对湿度和振动。观测是潜在过程加测量噪声；参考组与train没有人工注入故障。每批潜在过程180步，预测时只读取0–117步共118步观测，数据在观测时间后2步可用，预测时点为119，标签取样时点为180、报告时点为192。时间均为抽象步。

主要目标是人为定义的累计温度暴露代理：

```text
arrival_proxy = 10 + 0.03 × Σ max(潜在温度(t) − 298 K, 0)
                + Normal(0, 1²) + Normal(0, 0.5²)
求和覆盖180个潜在过程时间步。
```

298 K和系数均未按具体产品标定；固定研究终点180也不同于模拟到达时点125–155。该目标不代表纯度、酸值或真实质量损失。另设独立 `Normal(25,5²)` 的null_proxy作为负对照。

val按同一批次构造偏置1/2/4倍、漂移1/2/4倍和缺失视图。事件时长从4/12/24步抽样，起点、通道和符号固定后，三个幅度分别施加，**幅度不是按批次抽样的类别**。同一批次的过程和标签保持不变。工况记录延迟6/12步另作单因素压力条件。

本协议预测时所有批次仍在运输中；截止时刻的分层覆盖平稳运输和颠簸运输，不能称为已完成所有储运阶段的预测验证。

## 三、拟合方案与公平比较

评分沿用已冻结的分工况边际残差、因果EWMA（alpha=0.2）、独立参考校准q99和记录切换/缺失重置。参考和校准均使用当前118步窗口，没有复用旧180步实验阈值。隐藏过程、故障掩码和事件标签不进入预测特征。

B0使用观测及缺失标识，B1加工况，B2再加评分可用性，B3再加连续分数。为检查收益是否只是非线性特征变换所致，增加B2Q（标准化观测平方项）和B3Q（平方项加分数）；B2R使用从训练分数轨迹中按固定随机规则抽取的对照块，不读取目标。训练均值作为基本对照。

所有模型展开相同118步窗口，填补及特征标准化只在train拟合；每组、每目标都使用alpha={1,100,10000}三个候选，按原始val的MAE选择，随后锁定模型评价所有压力视图。训练没有故障增强。相同搜索预算不意味着特征维数和模型容量相同。

在当前已知工况和边际评分实现下，评分可用性与观测非缺失重复。因此B2与B1的预测实际上等价，本次最大差异约1.50e-12，为数值舍入量级；不能把本轮实验解释为证明可用性有额外收益。

共保存70组“种子×特征组×目标”的所选岭回归模型及训练均值对照。验证组参与参数选择，以下全部是**开发验证结果**，不能替代独立最终测试。

## 四、实际结果

以下为五个数据重复的均值±样本标准差，单位为任意代理单位。MAE越低越好；标准差不是置信区间，本轮不作统计显著性声明。副本和时间点不作为额外独立样本。

### 4.1 原始观测：预测任务可学，但评分组未领先

| 模型组 | arrival_proxy MAE |
| --- | ---: |
| mean：训练均值 | 4.5572 ± 0.2125 |
| B0：观测与缺失标识 | 1.7371 ± 0.0888 |
| B1：B0加可见工况 | 1.7524 ± 0.0830 |
| B2：B1加评分可用性 | 1.7524 ± 0.0830 |
| B3：B2加连续分数 | 1.8321 ± 0.0772 |
| B2Q：B2加观测平方项 | 1.7897 ± 0.0804 |
| B3Q：B2Q加连续分数 | 1.7960 ± 0.0792 |
| B2R：B2加随机分数轨迹 | 1.8154 ± 0.0844 |

基本观测模型明显优于训练均值，支持该合成任务存在可利用信号。增加工况或评分并未在当前模型与选择预算下自动改善误差；不能仅据方法结构预设收益。

### 4.2 主比较：连续分数的增量

差值定义为B3 MAE减B2 MAE，负数表示B3误差降低。差值的标准差从各种子配对差计算。

| 验证条件 | B2 MAE | B3 MAE | B3−B2 配对差 |
| --- | ---: | ---: | ---: |
| 原始观测 | 1.7524 ± 0.0830 | 1.8321 ± 0.0772 | +0.0797 ± 0.0769 |
| 偏置1倍 | 1.7967 ± 0.0795 | 1.8698 ± 0.0519 | +0.0731 ± 0.0702 |
| 偏置2倍 | 1.9299 ± 0.1037 | 1.9717 ± 0.0989 | +0.0418 ± 0.1774 |
| 偏置4倍 | 2.3244 ± 0.2593 | 2.2631 ± 0.3049 | -0.0613 ± 0.4785 |
| 漂移1倍 | 1.7664 ± 0.0814 | 1.8413 ± 0.0705 | +0.0749 ± 0.0723 |
| 漂移2倍 | 1.8090 ± 0.0772 | 1.8739 ± 0.0603 | +0.0648 ± 0.0760 |
| 漂移4倍 | 1.9683 ± 0.1164 | 1.9875 ± 0.1179 | +0.0192 ± 0.1970 |
| 单通道缺失 | 1.9440 ± 0.1535 | 2.2169 ± 0.4357 | +0.2729 ± 0.5176 |
| 工况记录延迟6步 | 1.7992 ± 0.0935 | 2.0225 ± 0.1899 | +0.2232 ± 0.2583 |
| 工况记录延迟12步 | 1.8580 ± 0.1208 | 2.1402 ± 0.2587 | +0.2822 ± 0.3727 |

四倍偏置下，仅3/5个种子出现误差降低，平均改善相对于种子间离散程度较小。缺失及记录延迟下平均退步较明显。所有条件均按预设方案保留，未根据这些结果调整生成器、评分参数或搜索范围。

### 4.3 必要对照与通道差异

平方项对照中，B3Q相对B2Q在十个条件中的10个条件平均MAE更高；本轮没有证据表明加入这种简单非线性项后，连续分数还能提供稳定增量。该对照并未穷尽所有非线性模型，尚不能把失败推广到全部预测器。

四倍偏置按实际注入通道分层如下。各层先在每个种子内计算，再跨种子汇总；不能直接把三个分层均值等权平均当作总体MAE。

| 注入通道 | B2 MAE | B3 MAE |
| --- | ---: | ---: |
| 温度 | 3.4124 ± 0.6889 | 2.6841 ± 0.7668 |
| 相对湿度 | 1.8372 ± 0.1348 | 2.0519 ± 0.1348 |
| 振动 | 1.7455 ± 0.0843 | 2.0565 ± 0.2193 |

温度直接进入目标生成公式，温度故障与其他通道故障的影响不同。上述异质性说明总体平均值可能掩盖收益与损害；这些分层是预设评价内容，但仍是开发验证证据。

在原始观测的独立负对照目标上，训练均值MAE为 **4.0325 ± 0.1780**，B3为 **4.0385 ± 0.1663**，未显示优于训练均值的平均表现。单靠负对照结果也不能证明所有泄漏风险均已排除。

## 五、已完成的检查与解释限制

工程检查包括32项相关测试、独立小样本端到端运行、正式数据补充语义审计、模型落盘重放和指标复算。补充审计核对了8,750个负对照标签及来源元数据；没有修改正式数据。所有正式验证预测在重载参数后完全重现。独立核算通过5,760行分层指标、300行配对差、1,212行汇总和210条候选选择记录。

本轮的主要限制如下：

1. 目标由预设温度暴露公式构造，尚无具体石化产品、实测质量标签及物理标定。
2. 正常参考是理想无故障样本；原始train到故障val存在分布变化。正常训练中的缺失/可用性特征恒定，线性模型无法由这些恒定列学出故障处理规则。
3. 分数由观测、工况及参考数据派生，预测增量不能自动解释为识别了真正错误的数据。
4. 岭回归及三个候选alpha只覆盖有限模型和预算；部分组选择搜索上界。没有据此认定更大范围搜索或其他模型必然无效，也没有事后扩大搜索来追求正面结果。
5. validation既用于选择又用于报告；普通LSTM和新test预测评价尚未开展，不能把本轮视为完整论文预测结论。
6. 复用Python 3.14.6环境（NumPy 2.5.3、scikit-learn 1.9.0）。与仓库Python3.11约定存在差异，已记录；未声称完成3.11兼容验证。

## 六、拟请老师审核的事项

1. 是否认可先将问题定位为“可靠性相关特征对合成终点代理预测稳健性的作用”，并把真实产品质量验证列为独立后续证据？
2. 研究最终对应哪类石化产品、哪项质量指标？可获得的环境记录、取样时间和报告时间能否支持该预测时点？
3. 面对本轮未出现稳定收益，是否先按相同信息范围开展普通LSTM对照，以检验模型容量影响，再决定是否研究修复或门控？
4. 如开展故障增强训练，是否将其明确列为另一种训练策略，并给予各比较组相同增强数据和选择预算？
5. 是否在上述模型与评价方案固定后，再对保留test进行最终评价，并如实保留负面结果？

建议先审核研究定位、代理标签与上述对照，再推进下一阶段。现有基础数据已经足以支持这些开发工作，目前没有必要为了获得正面结论重新生成同类大规模数据。
