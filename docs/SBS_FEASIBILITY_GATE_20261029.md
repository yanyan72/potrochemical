# 路线 B：SBS 数据可用性与最小实测设计

日期：2026-10-29。与多工况 Trust Score 主线并行。本文件是可行性设计，尚未实施现场试验、拟合企业模型或取得新结果。未收录企业原始数据及现场标识。

## 当前能做什么

本地接收记录表明，现有材料主要是产品检验结果，尚未形成“同一样品/批次—预测时点之前的过程观测—终点质量”的完整配对。普通软化点、老化后软化点、复检或调整记录须区分。缺少的历史温度、流量和操作记录保持缺失，不用经验补填后冒充实测。

**当前可以做任务和样品关系核对；不能用末端质检结果单独标定储存温度影响，更不能据此验证 Trust Score 的真实预测收益。**

一个简单的不可辨识例证：若 `软化点_i=初始状态_i+β×热暴露_i+误差_i`，只有终点软化点时，初始状态与热暴露均未知。不同的 β 和不同历史可以得到相同终点，单靠终点不能选择哪套过程解释正确。这是模型可辨识性说明，不是对企业数据作了回归或证明储存无影响。

## 最小实测：先证明变化能测出来，再讨论预测

固定一个产品等级和配方，取同一均匀母样，随机分到独立处理容器。由现场/实验室确定两个实际可行的储存条件 A、B 和两个时长 t1、t2，不照搬文献温度，不由研究者远程指定生产操作。

| 组合 | 独立处理单位数 | 测量目标 |
|---|---:|---|
| A、t1 | 3 | 与初始样品相比的变化 |
| A、t2 | 3 | 同条件不同持续时间 |
| B、t1 | 3 | 同持续时间不同条件 |
| B、t2 | 3 | 条件与持续时间交互的初步线索 |
| 初始基线 | 同母样留样并按方法复测 | 初始值及检测重复性 |

合计 12 个独立处理容器，初始留样另计。它们共享一个母批次，因此可支持该批材料的条件对比，不能当作 12 个独立生产批次或证明跨配方泛化。每容器的技术复测不增加独立处理样本量；如果处理是破坏性取样，不把同容器前后取样误当独立容器。

只需保留以下信息：母批/容器编号、条件、实际温度随时间记录、处理起止时间、是否及何时搅拌/转移、固定取样位置及采样时间、检测方法/普通或老化后状态、原始软化点和复测值。记录以实际可获得内容为准，不要求追补不存在的历史。

主要终点为 `ΔSP=终点软化点−初始软化点`，同时报告各容器结果与重复测量差异。先看处理变化是否超过检测与取样波动；这一小样本试验不以显著性检验作发表保证。若效应不清楚，先报告不能辨识，不直接训练复杂网络或无限增加样本。

## 从机制可行到预测任务，还有两道门槛

1. **预测可行：** 规定实际使用环节、预测时点和提前量；仅使用该时点已获得的信息。以初始质量保持不变、简单热历史模型作为基线。任何未来记录、终点检测或备注中的后验信息不能进入输入。后续以独立母批或按时间保留的批次评价，不能随机拆分同母样复测。
2. **RQ3 可行：** 在具有可预测信号后，才比较无评分、真实评分、随机评分，并区分真实仪表问题和人工注入故障。受控实测证明温度/时长影响，并不自动证明 Trust Score 有额外收益。

## 现场暂时无法实测时

可保留明确标注的假设模拟，但每条过程—质量关系必须列出来源和未知参数。老化主导、聚合物变化主导、两机制竞争应作为不同情景完整报告，不从企业末端标签逆向编写温度轨迹或选择最有利情景。若无法约束关键参数，则输出敏感性与可辨识性边界，不给出伪精确的企业预测性能。

文献依据见 [双线研究计划](DUAL_TRACK_RESEARCH_PLAN_20261028.md) L5/L6；它们说明软化点变化与材料、条件有关，可能呈非单调变化，不构成企业参数标定。本阶段未新增现场实验或假设模拟。

**下一步条件：** 若导师/现场具备上述最小实测条件，再安排具体方案；目前不向企业反复索要不存在的历史数据。路线 A 已独立开展小规模机制实验，不等待本路线。
