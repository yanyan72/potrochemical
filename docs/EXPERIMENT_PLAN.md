# EXPERIMENT_PLAN

## E0：数据生成正确性

目的：证明仿真器和异常注入没有逻辑错误。

检查：

- 数值范围；
- 随机种子复现；
- 异常掩码；
- 序列划分；
- 质量曲线合理性；
- 干净与污染版本对应；
- 不同工况可区分。

## E1：可信度识别

输入：污染观测数据。  
方法：标准化 + 收缩协方差 + 马氏距离。  
输出：距离、连续可信度、高/中/低可信组。

指标：

- Precision
- Recall
- F1
- PR-AUC
- 误报率
- 漏报率
- 每类异常召回率

图：

1. PCA 二维散点图；
2. 马氏距离时间曲线；
3. 可信度时间曲线；
4. 异常真值与预测对照；
5. 混淆矩阵。

## E2：质量预测基线

模型：

- Persistence
- Linear Regression
- LSTM

输入：

- 干净数据；
- 污染数据。

指标：

- MAE
- RMSE
- R²
- 按工况分组误差。

## E3：可信度增强

比较：

- 原始污染数据 LSTM；
- 中位数修正 LSTM；
- 可信度修正 LSTM；
- 可信度附加输入 LSTM；
- 后续可信度加权损失 LSTM。

原则：每轮只引入一个改变。

## E4：污染比例鲁棒性

污染比例：

- 0%
- 5%
- 10%
- 20%
- 30%

输出：

- 各模型 RMSE 表；
- 污染比例—RMSE 折线图；
- 相对性能下降比例；
- 每类异常性能。

## E5：物理约束

比较：

- 普通 LSTM；
- 可信度 LSTM；
- 物理约束 LSTM；
- 可信度 + 物理约束 LSTM。

场景：

- 小样本；
- 温度范围外推；
- 噪声；
- 参数变化。

## E6：动态参数消融

比较：

- 固定 A、Ea；
- 仅 A 动态；
- 仅 Ea 动态；
- A、Ea 均动态；
- 有/无范围约束；
- 有/无平滑约束。

## E7：区块链完整性

攻击类型：

- 上链后修改；
- 上链前错误；
- 时间戳篡改；
- 删除/插入记录。

比较：

- 只用哈希；
- 只用统计可信度；
- 只用物理可信度；
- 综合可信度。

## 重复性

主要实验使用 5 个随机种子。结果表包含：

- 均值；
- 标准差；
- 最佳/最差；
- 每次运行路径；
- 配置和代码版本。

## 结论约束

只有满足以下条件才允许写“有效”：

1. 对比基线明确；
2. 多随机种子稳定；
3. 误差改进不是数据泄漏；
4. 消融支持因果归因；
5. 结果在至少一种分布变化或污染场景下保持；
6. 统计与实际意义均合理。
