摘要中的“降低误报、改善定位、提升预测”是三个独立待验证主张；不得因为其中一项成立就保留另两项成功表述。条件残差公式和工况分组本身不是首次创新证据。

E1c–E1g形成评分边界、经典时序对照与重置消融证据，均不足以独立证明算法首创。E1g已补充重置单因素验证，但不消除全部相位混杂。下一轮先完成评分组件工程验收；质量预测主张仍待任务定义和实验。外部论文正文未修改，不能保证摘要/结论已同步；项目验收与论文写作分开。
