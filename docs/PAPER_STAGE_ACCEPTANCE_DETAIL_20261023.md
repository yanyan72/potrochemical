## 2. RQ3统计推断专项验收

**判断：已正确避免主要伪重复；五次重复的推断范围仍须收窄。** 本轮直接从存档预测重算5000条批次配对差，两项主结果与原汇总在1e−12以内一致。[4]

计算单位为：同一批次、同一视图内先做模型绝对误差差 → 每seed对500批及十视图等权平均，得到一个差值 → 对五个seed差值给均值、样本SD和 `t₄ × SD/√5` 区间。MAE可交换这两个平均次序，但**不能把配对视图当作独立重复**。

| 审查事项 | 判定及论文应写清的边界 |
|---|---|
| 模型、批次、时刻相关性 | 同seed各模型共用数据、初始化、日程，比较按配对计算；同批十视图共享标签。100个模型、25000个测试视图和时间点均不是独立样本量。主推断的外层重复数是**5**。 |
| 随机种子与模型方差 | 各seed更换数据/参考/val/test及模型随机种子，但同一数据集只有一个模型随机种子。可以估计本合成“数据＋训练流程”的联合波动，**不能分别估计数据方差、优化方差，或声称固定数据上多次初始化稳定**。 |
| 测试批次不确定性 | 每个拟合模型下500批提供条件性误差信息；这种批次SE不能代替包含训练变化的外层seed SE。当前五次外层重复包含测试抽样波动，但不能可靠拆分其来源。 |
| t区间 | 算术与df=4正确；仅五个外层观测，正态近似难以充分检验。应标为依赖该假设的近似区间，不称分布无关保证，也不凭区间跨0认定等效或“无作用”。 |
| 多重比较 | 两项主改善必须同时成立，不能挑一项；额外“五seed均改善”是稳定性门槛，不是另一个显著性证明。1820个诊断区间未校正，局部正负发现仅作探索性线索，不能批量称显著机制结论。 |
| 多轮研究与独立性 | 历轮复用了训练/参考，不能将各轮五seed相加，或合并为独立重复做元分析。新test独立于本轮选模，但方案受旧结果启发，只是固定模拟机制内的新样本评价。 |
| 测试隔离修正 | 软件fixture曾生成旧命名空间前8个test样本，其中4个临时预测；在查看研究测试指标前，正式test改为2026102301，模型未变。该技术修正必须保留披露，不能删除历史或称所有测试从未接触。 |

| 主比较（负为真实评分较好） | 五seed均值 [近似95% t区间] | 改善seed数 |
|---|---:|---:|
| 真实评分−无评分 | +0.00850 [−0.00888, +0.02588] | 1/5 |
| 真实评分−随机评分 | +0.00198 [−0.00832, +0.01227] | 3/5 |

**统计验收结论：**“未发现独立、稳定预测增益”可保留；“证明无增益”“与基线等效”“多数机制已确定因果关系”均不可写。当前负面结论无需靠增加同分布批次补救；若以后要分离模型/数据波动，才需要另定交叉重复设计，而不是把同一模型的测试批次重复计数。

## 3. 原题目、摘要和核心主张是否受支持

对齐版本为论文仓库已存中文Markdown，blob `9c07cc60c66e951d366f5911e2fda9d26d452be8`；只读核查，没有修改该仓库，也不声称已核对所有离线新稿。[5]

**原题目：**《一种面向石化储运质量预测的工况感知传感器级可信度估计方法》。

- **题目：有条件可保留，但不宜原样作为已验收结论。**“面向”可以表示研究用途，并不逻辑保证精度提升；然而当前没有真实石化质量目标，预测仅为合成暴露代理。若保留题目，摘要/方法/实验必须显著说明模拟范围与RQ3未获支持，不能让应用导向替代应用证据。
- **摘要：需要更新。** 已存稿没有明确声称预测误差下降，且正确区分了覆盖和条件化；问题在于尚未写入最新RQ3结果，只说明评分可作为预测特征。现在应补入公平预测检验、未获稳定增益及代理目标边界，不能继续仅报告RQ1/RQ2正面部分。
- **核心主张：部分支持。** 支持“工况相关观测偏离的通道级表达及受控权衡分析”；不支持“全面准确识别污染”“普遍减少误报”“稳定提高质量预测”“已验证工业适用性”。评分是派生表示，不是新的独立测量信息。
- **新颖性：未验收。** 公式实现、工程可用、哈希一致与大量实验均不能代替文献差异和方法贡献论证。

供导师选择的收窄题目：**《面向石化储运场景的工况感知传感器观测一致性评价与预测价值分析——一项模拟研究》**。这是建议，未替换现有稿件。

## 5. 哪些已足够，哪些是发表关键缺口

**已经足够，可停止增加数量：** RQ1的参考覆盖对照、RQ2残差/时序/重置的收益与代价展示、当前RQ3实现的公平检验和负面对照、数据与模型持久化、因果输入和复现检查。软件测试通过证明实现可信，不等同于论文已达到发表标准。

**提交论文前的必补项（主要是论证和写作）：**

1. 最新结果进入题目—摘要—研究问题—结论证据链；将“真实质量”与“合成代理”分开，将完成RQ3检验与支持增益假设分开。
2. 明确最接近方法的差异和贡献类型；当前尚未建立足够的算法新颖性证据。先确定目标期刊/论文类型，不能保证录用。
3. 统计说明补足外层n=5、模型/数据种子耦合、近似区间、诊断多重比较及多轮自适应研究边界；已有原始预测足以完成这项修订，无需重训。

**仅在保留相应主张时才构成实验缺口：**

- 保留“稳定预测提升”为核心创新：缺少正向、稳健、真实对照优势；应走路线B，不能靠新生成同分布数据反复碰结果。
- 保留“相对pooled的确认性普遍优势”：现有开发证据不足以支持此强度；RQ1最终评分测试未覆盖完整参考对照。可先收窄主张，不自动补一轮实验。
- 保留真实石化应用结论：缺少具体产品/质量指标、可信参考依据及独立应用证据。若真实数据拿不到，应选择明确的纯模拟研究定位，并论证生成机制的适用范围；增加随机种子不能代替外部有效性。
