## 评分阶段的结束条件

1. 默认策略明确，候选增强必须同时报告检出、实际误报、覆盖和恢复；无稳定优势可以不采用。
2. 数据与参考/校准身份可查，评分只读取观测及当前可用记录。
3. 公式、因果性、未知/缺失处理与存档结果通过测试，配置可复现。
4. 使用者可从文档运行批量评分，读取分数、可用性和告警；不可用不等于可靠。
5. 最终测试前冻结配置和评价协议。不能因测试表现不理想再回调方法。

不是所有工况达到最佳才算组件完成；但有失败边界的研究原型也不能被称为已工业部署。默认策略冻结不等于通用最优或创新证明。

## 质量任务最小输入

需要具体产品、目标指标及单位、取样时间、报告可用时间、预测发起时刻/预测目标时距、储运任务或批次ID。先提供字段说明即可，不要求一次提供全量数据。若只有到货质检，应定义为到货质量预测，不制造每步质量真值。

现阶段可推进评分组件封装及数据契约；质量标签未定义时，不把旧经验Q直接改名作为产品质量，也不实现未经授权假设的真实数据处理。

## 不纳入当前版本

生产推广、复杂物理动力学、区块链平台、可视化大屏和在线生产部署均需另定范围。论文排版、文献完善和投稿在另一条工作线进行，不阻塞已经满足上述条件的项目版本验收。
