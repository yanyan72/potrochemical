新增验证涵盖：

- 通道标准化仅取train；验证值不能改统计量；恒定训练通道在验证仍置零。
- 相同种子重复训练的参数、曲线与预测一致；梯度更新实际改变参数；选择最小原始val MAE轮次。
- 请求test在接触数据前拒绝。
- 临时80批夹具端到端运行两次，六组×两目标×两轮，保存参数、逐视图重放差0、逐元素预测一致、输入不变、拒绝覆盖、输出清单验收。

小夹具是隔离测试，不计入正式10,000批，也不把其结果作为研究结论。正式运行每模型40轮、隐宽32，测试夹具为2轮/隐宽4；测试中的全零提交占位仅在临时目录，不进入正式产物。

另对当前GitHub tree逐blob核对84个基础数据文件和9个既有源码，93/93一致；冻结发生器未改变。新增源码、配置、测试和文档经过差异审查与编译检查。

## 实现与剩余步骤

预测器使用普通单向LSTM时间均值读出；模型/目标分开拟合，隐藏真值不进入输入。评分和填补参数直接复用前次经外部manifest固定的存档。常量输入屏蔽、train统计、原始val选轮次、压力视图锁模评价均由冻结协议控制。

每种子新目录拒绝覆盖；每个已完成模型有本地checkpoint，种子完成即有清单并上传。完整运行后独立复算指标/选择记录。当前无正式LSTM性能数字，不能提前宣称有效。
