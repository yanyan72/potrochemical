# 储运 E1b 方法定义（论文3.4–3.5的实现依据）

状态r来自当时可用的运输/仓储记录；当前实验使用模拟真值作为理想已知状态。输入x含p个环境监测通道。所有参数只来自可靠训练片段；当前clean历史是理想化条件。

## 3.4 参考学习

完整序列拆成train_fit、train_cal、val、test。全体train_fit通道均值m、样本标准差s确定标准化坐标z=(x-m)/s。相同坐标用于所有方法。

对单一仓储参考、全部状态合并参考和各状态参考，分别在train_fit相应行上用LedoitWolf拟合中心mu和协方差Sigma；P=Sigma^-1。单一参考仅协方差/中心来自仓储，公共标准化来自全部train_fit。这种公共缩放不是新增状态标签信息。

## 3.5 两种通道评分

边际标准偏离：

$$a_j^{marginal}=|z_j-\mu_j|/\sqrt{\Sigma_{jj}}.$$

高斯条件残差：

$$\hat z_j=\mu_j-\frac{P_{j,-j}}{P_{jj}}(z_{-j}-\mu_{-j}),\quad a_j^{conditional}=\sqrt{P_{jj}}|z_j-\hat z_j|=\frac{|[P(z-\mu)]_j|}{\sqrt{P_{jj}}}.$$

这是可解释的候选基线，不宣称提出了新的高斯条件公式。近似高斯假设未必适用于真实储运数据。单个坏通道可能影响其他条件残差，因此专门检查bystander FPR。

每个参考/通道只用独立train_cal对应行的a校准q_j=quantile_0.99(a_j)。偏离比v_j=a_j/q_j，告警v_j>1；连续分数s_j=exp(-v_j²/2)。分数是单调有界一致性表征，不是概率；阈值位置分数为exp(-1/2)。0.99是预先固定的训练分位数，不保证validation恰好1%误报。

缺失通道边际分数不可用；条件残差在任何输入通道缺失时整行不可用。分工况参考遇到未覆盖状态也不可用。以NaN与available=false保存，不用0表示“检测到污染”。下游若使用数值占位，必须传入可用性指示并做消融。

## 评价支持集

主数值异常比较仅在完整观测行进行，所有方法保持同一支持集；同时报告全数据分数覆盖率。缺失数直接来自可见NaN，不作为算法发现隐藏故障的成绩。clean版本用于纯工况误报；observed用于检测、定位及牵连误报。Top-1在有人工污染的完整行上比较最高偏离通道是否正确，必须与Recall联合解读。

## 3.6 后续预测集成接口

在相同预测时刻输入观测+缺失指示、观测+缺失指示+工况、再增加分数+评分可用性三组。预测器家族、训练预算与标签一致，报告增加特征导致的参数数目差异。评分是派生特征，不是独立新信息；可用性与连续分数要分别消融。
储运质量指标、到货/抽检标签与出具时间尚未确认，本轮不实现或宣称预测收益。不会用环境异常分数替代质量标签。
