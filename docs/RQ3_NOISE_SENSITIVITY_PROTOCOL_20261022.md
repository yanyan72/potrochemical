# RQ3正常测量噪声局部敏感性协议

2026-10-22。用户授权按原计划继续模拟。本协议在新正式数据生成/评价前提交，只操作yanyan72/potrochemical。

## 问题与范围

上一轮当前冻结版本test已使用，LSTM十条件套件评分增量为负面结果，原结果不变。本轮检查：在未叠加人工故障、记录无延迟的正常观测条件下，正常测量噪声改变时，已存模型的误差及B3−B2增量如何变化？这是看到旧结果后开展的探索性、冻结模型分布扰动分析，不是新一轮独立方法确认，也不是对全机制或旧十条件套件的稳健性证明。

唯一变化因素是三通道测量噪声标准差的共同乘数[0.5,1,2]，不是方差乘数；原标准差[0.1 K,0.2 %RH,0.005 mm/s]。三档分别为[0.05,0.1,0.0025]、[0.1,0.2,0.005]、[0.2,0.4,0.01]。这些相对潜在过程波动很小，若影响小只能说明该局部范围内不敏感，不能宣称强噪声稳健。保持AR相关性0.85、工况/转场分布、标签系数及噪声、118步前缀和180步过程不变。真实企业数据对接另行进行，不将尚未取得的数据当作本轮依据。

## 新样本与配对

新随机命名空间20261022，种子42—46各250批，共1250个基础批次。只调用已保存发生器的val流生成新敏感性样本，不生成参考、train、test；配置中其他split规模仅为复用校验契约，不表示生成了它们。新ID含新namespace，与旧10000批不重合。五组模型对应旧种子42—46，新数据随机流独立；这是五个固定模型组在五组新数据上的评价，不重新采样训练模型。

每批三档噪声使用相同随机创新、潜在过程、工况和标签。原始生成器不改；分别仅缩放measurement_noise_std生成三档，验收truth/targets/IDs逐元素相同及噪声线性缩放（浮点容差1e-12）。保存三档可见输入、共享隐藏过程及标签；共3750个相关观测版本，不能写成3750独立批次。发生器返回的预备故障事件仅用于检查配对、未应用，不将其当成实际污染。无偏置/漂移/缺失/延迟注入。

## 模型和评价

加载原岭回归、LSTM、评分参考、校准、填补和标准化参数；不训练、不重校准、不改超参数或选checkpoint。两架构均保留mean、B0、B2、B3、B2Q、B3Q、B2R，两目标arrival_proxy及独立null。随机评分银行来自旧train，稳定ID选择轨迹；同批三档使用同一随机轨迹。隐藏过程、目标、事件不传入预测函数。标签生成用于模拟并单独保存，预测完成后才读取计算误差。

报告全部三档/架构/组/目标的MAE、RMSE和两种运输截止工况；配对B3−B2、B3Q−B2Q、B2R−B2。关注B3−B2及相对1倍档的增量变化：delta(f)−delta(1)，也报告各组MAE(f)−MAE(1)。五seed先各自算批次均值，再汇总均值、样本SD、df=4的95%t区间；所有区间均描述性、依赖小样本假设，不做多重未经校正的显著性筛选。三档共用批次，不能把档位当独立重复。保留所有正负结果；本轮不据结果追加档位或改变标签。
