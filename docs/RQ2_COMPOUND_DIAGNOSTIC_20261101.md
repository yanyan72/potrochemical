# 双故障压力诊断与单一候选机制

协议ef3dafe6，代码60595e17。五种子各64个原开发批次，26个配对视图，3个评分组；无预测训练。诊断全量15.4秒，结果目录`results/rq12/20261101/diagnostic_v1`。

## 发现

- 温度+湿度4倍偏置、延迟12步：joint12正常振动牵连误报8.59%，soft3为2.11%；joint12工况错误率2.12%，soft3为0.55%。无延迟时也出现4.28%对0.72%的牵连误报，提示并非仅由记录延迟解释。
- 温度+振动4倍偏置、延迟12步：joint12逐点召回60.72%，soft3为70.20%；工况错误率6.67%对3.19%。同一模型在单振动故障下仍改善事件检出，因此问题具有故障组合依赖性。
- 干净输入下joint12与soft3几乎相同；正常通道异常告警伴随相对配对干净观测的工况后验偏移，支持进一步检验“单故障互斥假设限制”这一机制，而非继续调整评分阈值。
- hard组用匹配延迟校准的统一逐通道阈值，干净误报与召回权衡明显；不把它当旧硬工况模型所有配置的代表。

所有组合、符号、起点、工况和种子均保留。开发诊断不用于改写冻结RQ3。

## 唯一轻量候选：可组合故障掩码

令 f=(f_T,f_H,f_V)∈{0,1}³，保留三工况，得到24状态。三个故障位各自采用原参数的两状态马尔可夫链：初始故障概率0.01，正常→故障0.001，故障→正常0.1。

P(f_t|f_(t−1))=∏_j P(f_tj|f_(t−1)j)，
Σ_(z,f)=Σ_z+κ²diag(f⊙diag(Σ_z))，κ=4。

工况转移、可见记录似然0.9、参考参数、CDF残差、EWMA和q99校准不变；在原训练校准集重新计算该分支阈值。没有新拟合的自由参数。独立位先验与原互斥先验略有差异（无故障初值0.970299对0.97），不声称只改变状态数而所有概率完全相同。

只运行这个固定设置；下一组每seed第64—127个旧val批次与本诊断不重叠，保持相同26视图、原3组及候选。比较双故障检出/正常误报/工况污染，并检查单故障与干净观测代价。它是开发验证，不把已知数据家族和旧val改名为正式独立确认。软件测试另验证因果前缀、后验归一、κ=0退化及双位可识别。
