# PROJECT_BRIEF

## 当前主线（2026-09-18用户确认）

面向石化产品运输与仓储，研究工况感知的传感器级观测一致性评价，并进一步检验它对质量预测的帮助。生产环节仅在Future Work讨论，不将生产牌号、装置工况和储运阶段混写。

当前三个研究问题：
- RQ1：工况条件化参考是否优于单一状态参考和全部合法状态合并参考？
- RQ2：逐传感器分数能否定位污染，并控制对干净通道的牵连误报？
- RQ3：观测+工况+评分是否优于观测+工况，在相同预测器下改善质量预测？

## 研究边界

一篇论文，论文与实验并行，最终补充真实过程数据。真实数据后续由用户提供，当前先使用明确标记的模拟数据。不能假装已知具体产品、化验指标、采样频率和安全阈值。

储运状态来自预测时已经可用的记录。当前模拟采用仓储、平稳运输、颠簸运输标签作为理想已知条件。合法状态表示可能发生的正常观测分布，不保证质量合格或环境安全。未知/估计工况为后续实验。

先做可解释评分和固定预测器增量比较，修复作为独立后续消融。区块链、复杂物理动力学和平台不纳入当前论文核心。

## 当前可执行里程碑

E1b基准、E1c压力、E1d EWMA、E1e有限窗口及E1f受控事件/CUSUM已完成。W=9完整SMA和固定k=.5连续CUSUM均不升级为默认方法。E1f分开事件时长/数量/起点，发现跨切换检出退步和累积拖尾代价。下一步优先仅改变可见工况切换处理，严格报告覆盖与误报，不再扩展无边界平滑参数搜索。质量目标明确后并行启动预测基线，避免长期停留在检测。历史四变量模拟保留用于复现，不改名为已标定储运数据。

## 质量目标尚未冻结

运输仓储的质量可能只有到货或抽检标签。收到真实数据后，根据标签时间确定未来质量、当前软测量或到货质量任务；不能默认每步都有质量真值。内部可并行设计预测协议，但本次不实现未定义的质量目标。原模拟Q是旧经验代理，不能无解释沿用为产品质量。

## 最低证据要求

合理基线、多种子、逐状态结果、无泄漏、通道定位、固定预测器的可归因增量、真实数据边界。不能保证三项假设均成立；失败结果同样入库，不承诺指标或录用。
