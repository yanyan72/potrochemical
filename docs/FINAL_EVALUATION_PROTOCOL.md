# v0.1 最终保留集协议（运行前冻结，2026-09-27）

## 范围和选择
本轮是现有评分组件的收尾验收，不增加探索性实验。默认regime_marginal + EWMA(alpha=0.2)，q99、zero初始化、可见记录切换/缺失/序列边界重置。理由是单通道可解释性、缺失隔离与减少条件残差牵连；不主张它在每个场景最高分。固定对照：边际point、条件point、条件EWMA，全部reset，复用E1f存档训练参数；不采用SMA、CUSUM和carry。演示seed42在test前指定。

## 测试数据
E1c存档base_data.npz的test：种子42–46、每种子3工况×4完整序列×180步。按原配置均值/尺度还原其标准化噪声，仅供生成同族切换场景，不从test估计参数。E1f的12个场景、时长/数量/幅度/转场偏移全部照用，污染事件随机空间固定20260927；训练尺度来自原scales.json。每种子12条独立测试序列跨场景配对复用。真工况、clean和mask只用于生成及评价。参数与数据在公开仓库可读，因此不声称外部保密盲测。

## 指标和统计
两视图clean/observed；4方法；all及3真实工况；全程/真实转场12步/稳定段/记录改变后12步/其余。沿用coverage_metrics：F1、Recall、Precision、AP、干净通道FPR、牵连FPR、Top1及随机参照、全故障集合、全时间轴F1/Recall、可用覆盖、事件后12步误报、新误报起点率。事件评价：fresh onset、any active、检出延迟及漏检以事件时长惩罚的capped delay、可用性。每种子先聚合，再mean±样本SD、有效seed数；不同窗口会重合，不能相加。

## 冻结和验收
配置见configs/scoring_release.yaml；实现提交后才运行正式评价。核验E1c/E1f所有输入哈希和来源关联；检查序列划分互斥。保留每个模型、test场景、事件、分数与元数据；结果目录不可覆盖。功能验收要求接口/校验/评分一致/因果/隔离/复现测试通过。科学性能不预设成功门槛，完整公开弱偏置漏检、迟滞和误报。

正式test只运行一次，若技术失败必须记录原因，不可按结果改方法。之后仅核对已生成产物。该test从此已使用，未来方法选择需要新的独立评价设计。质量预测、真实数据、故障外推能力都不由本次验收证明。
