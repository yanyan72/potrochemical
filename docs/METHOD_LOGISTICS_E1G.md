# E1g：工况切换时重置与保留EWMA记忆

E1f同数据配对消融，不是新盲测。项目代码/实验与论文写作分开验收，不编辑外部论文。

## 唯一变化

当前可见工况r_t下的有符号标准化残差u_t，固定alpha=.2：reset在r_t变化时先清零z_(t-1)，carry不清零；之后都更新`z_t=.2*u_t+.8*z_(t-1)`。当前参考和q99阈值始终用当前记录工况，carry只保留标准化残差历史，不沿用旧工况原始单位统计或阈值。

序列起点为零，残差缺失输出NaN/available=false并清空该通道。未知工况产生NaN残差，不跨未知区间传递记忆。条件残差需要整行完整，边际只需本通道完整。旧API默认reset=true，历史行为不变。跨工况标准化残差可比较是待检验假设，特别是条件关系改变时；本开关不是算法首创声明。

## 固定数据、模型与校准

E1f五种子×12场景，旧六种组合（边际/条件×逐点/EWMA/CUSUM）只读引用，新增边际/条件EWMA carry。评分入口不接收真工况、污染mask或事件位置。train_fit参考、alpha、q99、数据及事件固定。

train_cal是固定状态完整序列，两策略校准分数必须逐元素相同，运行中核验后复用旧阈值。固定状态validation亦需完全相同。旧EWMA复算与存档逐元素一致，避免接口修改暗中改变基线。

## 指标

沿用全时间轴F1/Recall、实际clean/牵连/拖尾FPR、事件新告警、漏检截断延迟与除以时长后的延迟、覆盖；按seed先聚合再均值/样本标准差。8种组合共同支持，保留全时间轴漏检。

窗口：all、transition/stable（原真工况切换后12步）、record_transition/record_stable（可见记录变化后12步）。起点不算切换；窗口可重叠，不相加。延迟12步场景的record_transition检验记录恢复后的告警延续。clean视图无注入故障，其人工事件位置命中只作诊断，不当检测成功。

输出每seed的carry-minus-ewma配对差、原始carry分数、开关模型、校准审计、环境/输入输出hash。旧分数与数据通过manifest引用。相同q99不保证实际等误报；禁止依据本轮validation重新调参。

## 验收与限制

验收要求实现正确、重放一致、可复现且检出/误报/覆盖/恢复同时报告，不预设carry必须胜出。变化可归因于同数据下的重置策略开关，但不推广为真实转场或自动工况识别。仍为clean oracle训练、瞬时模拟切换和反复使用的开发validation，test保留；无质量或工业结果。
