# RQ3 配对储运模拟数据协议

冻结日期：2026-10-19。用户批准后先提交协议，再实现并生成。当前为数据准备阶段，不运行预测器、不评价保留测试集，不以预测效果反向修改发生器。

## 任务与证据范围

一批货物为一个独立基础样本。输出终点累计温度暴露代理 arrival_proxy，任意代理单位；不是已确定产品的纯度、酸值或其他化验值，不来自金陵石化。温度、湿度和振动为环境示意通道，不等同于介质状态。只支持同一模拟族的受控方法验证；不证明真实故障或工业质量预测有效。

每种子2000批：reference_fit150、reference_cal100、train1000、val250、test500。五种子42–46为独立数据重复，共10000批；模型种子与数据种子后续分别记录。每批180步，观测可用时间=time_step+2；第119步预测第180步取样、第192步报告的代理标签，因此输入窗口0–117共118步。第180步是固定研究终点，实际模拟运输到达发生在125–155步，不把二者混称实际到货取样。时间为抽象步，无真实日历外推。

## 过程、测量与标签

仓储→平稳或颠簸运输→仓储；离开步25–50，到达步125–155。运输类别按独立随机抽样，不用批次序号编码类别。各工况均值/标准差、共享AR(1)系数0.85和载荷沿用既有示意分布；每批另有随机偏移。湿度潜在过程限制0–100，振动非负；观测加测量噪声后不人为裁剪。转场是瞬时统计切换，不宣称物理连续转场。

z为潜在过程；原始观测x=z+独立零均值测量噪声。reference_fit、reference_cal和train均无人工注入故障，但不使用无噪声z代替观测。参考批次“确认无故障”仍为理想假设，不代表已解决从污染历史中选择可靠样本。

arrival_proxy = 10 + 0.03 * sum(max(z_temperature - 298, 0)) + Normal(0,1^2) + Normal(0,0.5^2)。积分步长为1；298K不是安全限值；系数未做物理标定。null_proxy独立Normal(25,5^2)，仅作负对照。过程、测量噪声、质量批次效应、化验噪声、负对照、故障分别使用独立随机流。污染或记录延迟开关不能改变潜在过程或标签。温度含有代理信号是发生器假设，不能据此证明真实机理。湿度和振动不被强制赋予直接质量因果作用。

## 原始与污染配对

主训练只用train原始观测；val/test保留同批次原始、偏置、漂移、缺失副本。每批一个单通道事件；通道、符号、持续时长4/12/24和起点独立于目标抽样。起点在整个可见前缀内均匀选择合法位置，不锁12步网格。偏置和漂移使用相同起点/通道/符号/时长，幅度1/2/4倍该可见起始工况的reference_fit观测标准差。漂移从非零的1/duration幅度线性增加至设定幅度；缺失为NaN。此采样只代表“存在一个注入事件”的压力条件，不估计实际故障发生率。

主比较工况记录即时且相同；记录延迟0/6/12步另作单因素压力视图，不与主污染比较混合归因。模型获得的是对应历史观测时刻可见的记录，不用事后恢复的真实状态回填历史。

## 对齐论文与后续模型

对应论文3.3终点目标，3.6 B0观测+缺失、B1加工况、B2加可用性、B3加连续分数，4.2原始训练/配对评价。主判断B3–B2；保留B1、训练均值及随机评分对照。岭回归按论文展开同一窗口，普通LSTM作同信息范围对照；各组分别拟合，相同选择预算。评分从窗口起点清零，reference_cal也采用同样118步前缀和重置规则，不能沿用旧180步校准阈值。评分与预处理不读预测截止后的观测。

本轮只提供数据和输入加载器，不拟合上述模型。后续在新协议中冻结预测器训练/选择、评分校准、评价指标和最终测试流程后，才评价test。已用旧评分test不复用。公开保存的test只能称流程保留集，不称保密盲测。多副本、时间点和多事件不是额外独立样本。

## 文件契约与防泄漏

每seed/split保存inputs.npz：observations[N,118,3]、recorded_regime[N,118]（整数0/1/2，对照配置顺序）、sequence_id、time_step[118]、available_time[118]；不含标签、真工况、clean或mask。每个预测split单独保存targets.csv：ID、两个代理目标及prediction/sample/report时间。参考不导出质量标签。

evaluation_only/<seed>/<split>/truth.npz保存完整潜在过程和真实工况，用于审核而非预测输入。val/test的events.csv和训练来源fault_scales.json保存生成污染所需稀疏信息；污染副本由只读加载器按事件重建，避免存储相同观测的重复副本。reference_fit尺度仅用其可见前缀拟合；test改变不能影响其他组或污染尺度。以ID连接标签，不把ID、split、事件表、未来序列或目标时间作为特征。参考、训练、验证和测试ID互斥。

配置、源码身份、依赖版本、每文件SHA256和结构审计随数据保存。test仅做结构与完整性校验，不输出目标分布、预测指标或选优信号。文件哈希仅证明完整性，不证明真实传感器准确。

## 验收

同配置逐数组复现；改变test数量不影响训练；污染/延迟不改变标签；mask匹配实际变化；无未来输入；参考仅可见无注入观测；合法环境升温可改变代理而故障不改变代理；正常噪声与人工故障区分；五种子、完整批次隔离、逐组计数和输出hash一致。输出路径已存在时拒绝覆盖。
