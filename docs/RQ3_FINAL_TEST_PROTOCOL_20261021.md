# RQ3 当前冻结模型的保留测试协议

日期：2026-10-21。用户在询问正式RQ3结果时间后授权“你模拟吧”，按前述冻结比较、执行保留测试、上传并汇报的安排实施。该协议在任何本轮test预测前推送。

## 问题与科学范围

检验当前“连续一致性评分作为附加输入”在相同预测器内是否改善合成终点代理预测。已有岭回归和LSTM开发val结果均未显示总体评分增益，此事实已知；现在对已选定模型作一次保留test评价，不做额外搜索以追求正面结论。

基础数据为10,000批重建版，生成器及数据不变。五seed各500个test批次，总计2500个独立基础测试批次；每批10个观测视图为相关配对，不计作25000个独立新样本。预测仅用118步可见观测，目标仍是180步温度暴露代理和独立null。全部人工机制、抽象时间、未按具体产品标定；最终测试只检验该模拟任务，不构成工业有效性证据。累计标签包括预测前暴露，所有截止工况均在运输中。

## 冻结模型和比较

仅加载已归档的岭回归与普通单层LSTM参数、train标准化/填补、参考评分及校准。两个模型家族都评价mean、B0、B2、B3、B2Q、B3Q、B2R；岭回归B1与B2冗余，保留源参数但不重复展示B1。mean直接加载原train均值；随机分数库只从train观测和冻结评分构造，不用test标签。

每个seed/目标所选岭alpha、LSTM轮次固定，不重新训练、不合并train/val、不根据test改变参数、目标、评分、输入或模型。LSTM沿用train恒定特征全划分置零的既定限制；不同输入维度及跨架构预算不等价的限制保留。

10个视图：original、bias1/2/4、drift1/2/4、missing、delay6/12。主配对B3−B2，次对照B3Q−B2Q和B2R−B2；负值为误差降低。报告所有视图MAE/RMSE及截止工况、故障通道、时长分层；事件只供事后评价，不进入预测器。

## 在test前明确的主终点

唯一主终点：**LSTM、arrival_proxy、B3−B2，在十个预定视图等权评测套件中的MAE差**。每seed先计算各视图每批绝对误差差，再按批次及十视图平均，最终仅以五个seed作为独立重复，报告均值、样本SD和双侧95% Student-t区间（df=4）。十视图等权是人为评测套件权重，不代表真实现场故障发生率；同批次不同视图不当作独立重复。

主终点区间上界<0，支持当前冻结套件的平均误差降低；下界>0，表明该套件平均误差升高；跨0则不支持明确方向，也不能宣称等效。该区间依赖五个seed差值近似正态等小样本假设，不应解释为精确或工业保证。

原始条件、九个压力视图等权平均、逐视图、岭回归和其他比较均为预先列出的次要/描述性结果；同样报告逐seed及区间，但不据多个未校正区间挑选“显著”子组或宣称全面有效。主终点在看过开发val之后、打开test之前确定，透明记录这一区别。使用一个预定主终点，避免test后改变权重或挑选有利条件。null只作负对照，不作为方法成功判据。
