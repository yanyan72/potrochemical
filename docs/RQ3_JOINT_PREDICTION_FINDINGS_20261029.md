# RQ3：21 模型开发实验结果与创新深化

2026-10-29。本轮已完成：三个数据种子 × 七组，共21个预测模型；复用3000训练批次、750验证批次，各六个配对观测场景。原潜在过程与质量标签未改变。

## 研究发现

**评分指导修正具有可重复的强故障收益，但全时段修正损失了正常场景表现。下一步最值得深化的是选择性修正，而不是再增加评分复杂度。**

| 六场景等权 MAE，越低越好 | 三种子均值 | 种子间 SD |
|---|---:|---:|
| N：无评分 | 1.60405 | 0.06118 |
| OT：旧评分拼接 | 1.61102 | 0.05818 |
| NT：新评分拼接 | 1.60854 | 0.06223 |
| ZG：新评分单纯门控 | 1.61362 | 0.07334 |
| NG：新评分＋工况参考修正 | 1.61156 | 0.07282 |
| RG：随机评分＋相同参考修正 | 1.61388 | 0.06177 |
| AG：去掉故障假设后的参考修正 | 1.61110 | 0.07489 |

新评分拼接比旧评分平均降低 MAE 0.00248，三个种子中两个改善，幅度较小。NG 全场景相比 N 高0.00751，当前总体 RQ3 稳定增益尚未获得支持；但分场景实验揭示了有价值的作用路径。

## 2. 收益主要来自温度故障，说明任务关联性很关键

强偏置下 NG−N 的 MAE 差：

| 故障通道 | 正确记录 | 延迟记录 | 各种子趋势 |
|---|---:|---:|---|
| 温度 | **−0.18031** | **−0.19585** | 三个均改善 |
| 湿度 | +0.03169 | +0.02615 | 三个均退步 |
| 振动 | +0.05106 | +0.03932 | 三个均退步 |

原质量代理主要由温度暴露构造，湿度/振动不是独立直接质量驱动。因此，振动识别更准确与质量预测明显改善并不必然同步。这里应深化的是“测量可靠性、参考可信性与预测任务相关性如何共同决定是否修正”，而不是给模拟标签人为增加湿度/振动效应。

配对干净基线进一步提供线索：温度强故障的额外误差得到约0.186/0.193的缓解；湿度强故障也有约0.012/0.023的故障增量缓解，但被正常表现损失抵消；振动的故障增量未见相应改善。详细逐种子、切换位置和末端工况结果全部保存。

## 3. 拼接、单纯门控和参考修正的区别

拼接只把分数交给预测器，本轮收益很小。单纯门控和参考修正都能降低强偏置误差，但对干净和弱漂移场景造成约0.03的MAE代价。NG−ZG总体为−0.00206，仅一个种子总体改善；延迟弱漂移下三个种子均有小幅改善，提示工况参考可能在记录不确定时更有价值，但目前不是普遍优势。

NG−AG总体仅+0.00046，未显示联合故障推断在下游的独立优势。联合机制已改善评分参考污染；本轮说明其预测价值还取决于怎样使用分数。论文应呈现这条证据链，而不把所有修正收益都归给联合推断。

## 4. 为什么考虑选择性修正：数学分解与实际诊断

当前修正为 `x̃=Sx+(1−S)c(q)`。令配对无注入观测为 x⁰，e=x−x⁰，b=c(q)−x⁰，则逐点严格成立：

`(x̃−x⁰)² = S²e² + (1−S)²b² + 2S(1−S)eb`。

三个项分别对应残留污染、参考替代偏差和交叉作用。该恒等式已逐点核验，诊断使用配对无注入观测，而非隐藏真值。

在温度强偏置窗口，相对配对干净观测的标准化均方差从4.4679降到1.2918（正确记录）/1.0334（延迟记录），说明修正确实压低污染。与此同时，干净温度点虽然只有约0.80%越过告警阈值，平均仍被收缩6.25%，额外产生0.00926的标准化替代偏差。这与正常预测损失相吻合，为“无需对每个正常点持续收缩”提供了可检验解释，尚不把关联当作唯一原因。

## 论文增量与最小下一步

本轮可形成的研究主张是：**工况不确定下，评分用于异常识别与用于预测修正需要不同的决策规则；参考修正能够恢复任务相关故障损失，但广泛替代正常波动会抵消收益。** 原 Trust Score 和 RQ1—RQ3 结构都可保留，联合工况—故障推断作为参考选择层增强。

相关研究为这种深化提供基础：[GRU-D](https://pmc.ncbi.nlm.nih.gov/articles/PMC5904216/)研究缺失值随时间向经验均值衰减；我们的切入点是仍有观测但可靠性不确定时，如何结合工况参考决定修正。[Feng等多模型诊断与数据协调](https://aiche.onlinelibrary.wiley.com/doi/abs/10.1002/aic.16435)研究故障识别和信号重建；本项目可进一步贡献共同工况信息下的公平预测对照，以及修正收益与正常信息损失的分解。当前是有依据的增量方向，不主张首创门控或多模型推断。

**下一步只验证一个轻量变化：沿用现有评分阈值，将连续全时段修正改为有证据时才介入。** 候选形式为 `λ=max(0,1−S/S₀)`、`x̃=x+λ(c(q)−x)`，其中 `S₀=exp(−1/2)` 对应既有r=1告警阈值，不重新用质量结果挑阈值。正常一致观测保持原值，低可信点逐渐趋向工况参考。这是本轮结果启发的探索性假设，尚未执行。

最小规模为三个种子×真实评分/随机评分/去故障假设三组，共9个新增模型，复用本轮N及全时段修正模型；数据、种子、预算均保持一致。首先判断能否保留温度故障收益并减少干净代价，再决定五数据种子、独立优化重复和新留出确认。本轮没有追加这9个模型，也没有修改当前21模型。
