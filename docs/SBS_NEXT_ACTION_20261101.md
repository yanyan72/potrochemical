# SBS并行路线：一次性落实清单

2026-11-01。现有资料以产品检验为主，本轮未收到新的已核实过程—化验配对或现场实施确认。保留10/29可行性方案，不追加假设模拟，不由末端软化点反推真实温度历史。

可一次性转交现场确认（本任务没有擅自发送企业消息）：

| 需要落实 | 最简回答/记录 |
|---|---|
| 用途 | 希望在什么时刻、提前多久知道哪一种质量指标？ |
| 样品关系 | 能否固定一个等级/配方及同一母样，区分普通、老化后、复测？ |
| 实施能力 | 现场是否能安排2个可行条件×2个时长×每组合3个独立容器，另留初始样？具体条件由现场决定 |
| 实际记录 | 容器号、实际温度/起止时间、搅拌转移、固定位置取样、原始检测及复测值，哪些能够真实记录？ |

先比较终点相对初始的变化是否超过检测/取样波动。12个容器共享母样，不能当12个独立生产批次；条件可测效应也不等于已经验证预测或Trust Score增益。

11/04前优先确认可执行性；11/11若仍无关键配对与实施条件，SBS不进入本月主实验。若新数据到达，先检查真实批次/时点/记录可用性，不改变已经冻结的主线方法。案头工作仍遵守原不超过6小时预算，不重复索取不存在的历史。
