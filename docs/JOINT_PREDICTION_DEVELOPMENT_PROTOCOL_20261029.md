# RQ3 共享工况—故障评分：21 模型预测开发实验

用户已验收评分机制并授权继续。目标是发现评分改进如何转化为预测价值，比较拼接、门控和工况参考回填；保持原 RQ1—RQ3 框架。先提交本协议和配置，再训练。当前尚无本轮预测结果。

## 数据与预算

三个数据种子 42/43/44，各复用原重建版 1000 train、250 val；预测前 118 步的到达质量代理 arrival_proxy。评分仍用已冻结正常参考与候选参数。不生成新潜在过程，不改标签，不读 test。六个视图沿用 A0 的记录正确/延迟12步 × clean/drift1/bias4。每批一个12步故障，温度/湿度/振动、正负符号、首次工况切换前6步/后18步均衡安排；前60批复用 A0 已存事件，其余批次用固定新事件随机流构造配对观测。所有组训练时使用同一逐轮视图日程和标签。

七组 × 三数据种子 = 21 个单层 hidden32 LSTM；各40轮，batch128，即320次更新；AdamW lr=.003、weight_decay=.0001、梯度裁剪1。同一独立优化种子29001、同一批次打乱种子39001跨组/跨数据种子使用；视图日程由49001和数据种子确定。所有组18输入、6689参数、相同初始权重。每轮在同一六视图 val 均值MAE上选最早最优checkpoint，不调其他参数。

## 对照与公式

公共输入：原始观测、缺失标志、可见工况one-hot、可评分标志、**候选共同工况后验 q**；另预留3个评分槽。公共原始输入的标准化仅从共享训练视图拟合，全组相同。当前六视图无缺失，但保留原字段。

设标准化观测 z=(x−a)/b，候选参考均值 c(q)=Σq(k)μ_k（换回物理单位），标准化参考 m(q)=(c(q)−a)/b。原 Trust Score 映射保持 S=exp(−r²/2)，r为冻结阈值归一化后的绝对平滑残差。

| 组 | 观测输入 | 附加评分 | 回答 |
|---|---|---|---|
| N | z | 0 | 同信息无评分基线 |
| OT | z | 原记录工况评分 S_old | 原方法拼接 |
| NT | z | 新联合机制评分 S | 新旧评分比较 |
| ZG | S⊙z | 0 | 单纯评分门控；零点为训练总体均值，不是0 K |
| NG | S⊙z+(1−S)⊙m(q) | 0 | 评分引导工况参考修正 |
| RG | S_random⊙z+(1−S_random)⊙m(q) | 0 | 相同修正、随机评分对照 |
| AG | S_κ0⊙z+(1−S_κ0)⊙m(q_κ0) | 0 | 去掉故障假设的评分/修正消融，公共输入q仍为新候选 |

**本轮实施前调整**：为回应用户明确要求，在既定七组预算内用 ZG 替代随机评分拼接 NR。保留随机评分融合 RG。因而 NT−N 只评价拼接实用效果；评分特异性的更直接控制在 NG−RG。此调整不依据预测结果。

随机评分整轨迹只从六视图 train 评分池取样，训练接收批次排除自身所有视图，验证不使用任何验证评分池。随机映射对一个接收批次的六视图固定。故障mask、事件信息和真实工况不进入预测特征。

## 分析与研究判断

主报告为每组六场景等权MAE、逐数据种子配对差；同时报告RMSE、故障通道、故障相对切换位置、预测末端原工况分层。相同批次的视图先配对，外层是3个数据种子，给均值/SD和各种子差值，不把视图或批次数当训练重复。

重点比较 NT−OT（评分替换）、NG−ZG（参考回填）、NG−RG（评分针对性）、NG−AG（联合故障机制）。对同一批次比较强故障与clean下的预测误差变化，判断收益来自故障损失恢复还是正常信号收缩；所有条件保留。原计划的1%收益/2%clean损失筛查仍计算，作为描述，不机械地代表研究价值。后续依实际效果、重复趋势、可解释消融共同判断；不得靠换标签、删不利种子或试多个配置制造收益。

本轮交付21模型及其参数、840行训练史、逐批预测、完整分层表、方法公式、静态论文图及简洁研究报告。软件微型测试仅验证执行路径，不计为科学模型；训练后从存档checkpoint重放，独立重算预测表。SBS不改变当前主目标，不在本轮加入虚构过程数据。
