# 真实数据接口（Pending external data / 等待外部数据）

当前没有实验室或石化企业真实数据。本目录只保留未来接入位置和字段要求，不包含、也不得生成任何伪造数据。

## 当前状态

- 真实实验室数据接入：等待外部数据；
- 真实数据清洗：等待外部数据；
- 真实工业验证：等待外部数据；
- 当前算法开发继续使用明确标记为 synthetic/simulated 的可控仿真数据。

## 未来最小字段

获得数据后，至少需要确认：

- 独立序列或批次标识；
- 时间戳或有明确采样间隔的时间索引；
- 温度及单位；
- 压力及单位；
- 振动或可替代过程变量及单位；
- 浓度或其他关键工艺变量及单位；
- 与时间或批次对齐的质量化验指标、单位、检测方法和检测时间；
- 工况标签或可用于恢复工况的操作记录；
- 缺失、校准、维护和传感器异常记录（如存在）；
- 数据来源、使用权限、脱敏要求和版本信息。

## 接入前检查

未来接入必须另立执行计划，先完成字段映射、单位统一、时间对齐、缺失机制分析、序列级数据划分和来源审计。标准化参数、阈值和协方差只能从训练集拟合。任何真实数据结论必须与仿真结论分开报告。
